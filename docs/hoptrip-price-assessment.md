# HT-09 — объяснение цены и свежести

Карточка, окно оценки и страница предложения используют общий `PriceAssessment`.
Главный текст — цена ниже, на уровне или выше медианы **сравнимых наблюдений**.
Это не скидка продавца и не сравнение со всем рынком.

Сравнение разрешено только для CURRENT из сохранённого `score_explanation`,
при целочисленной выборке от 5, положительных текущей цене/медиане и конечной
записанной разнице. Цена расчёта должна совпадать с ценой перелёта и показанной
ценой на человека. Legacy `discount_percent` не используется.
PROVISIONAL, LEGACY, UNAVAILABLE, неполные и несогласованные сведения показывают
ограничение без процента преимущества. Медиана при этом не рекламируется.

Отдельно показаны число наблюдений и ограничение выборки. Порог 5 соответствует
существующему MIN_PRICE_SAMPLES модели flight-v3. Это минимальное число для
расчёта, а не статистическая гарантия репрезентативности.

Время берётся из сохранённого объяснения:
- SOURCE → «Obserwacja ceny u źródła»;
- FIRST_SEEN → «Pierwszy zapis tej ceny w HopTrip»;
- без пригодного объяснения → last_verified_at с нейтральной подписью
  «Czas zapisanej obserwacji» и явно неизвестным происхождением времени;
- без корректной даты → время неизвестно.

Время отформатировано в Europe/Warsaw и подписано «czas w Polsce».
Сейчас/API fetch/момент открытия страницы не подставляются как обновление цены.
Отдельное предупреждение: наличие и конечная цена проверяются у партнёра,
подтверждения на живой странице продавца у HopTrip нет.

Балл подписан «Ocena oferty cenowej»; на карточке перемещён из верхнего бейджа
под объяснение. Формула и распределение баллов открываются через нативный
`details`; методология доступна отдельно даже при неизвестном расчёте.
Код backend, веса, округление, сортировка, поля API и миграции не менялись.

## Воспроизведение

1. Открыть предложение с CURRENT: проверить процент/направление относительно
   медианы, число наблюдений, подпись времени и предупреждение о доступности.
2. Открыть объяснение балла клавиатурой; формула первоначально скрыта.
   Раскрыть «Jak obliczono …», затем Escape: фокус возвращается на ссылку.
3. Открыть PROVISIONAL / LEGACY / предложение без объяснения:
   отсутствует обещание преимущества цены, ограничение доступно без раскрытия.
4. Сверить время на карточке и деталях. Проверить узкий экран и методологию.

Локальные browser fixtures: browser-deal (24 наблюдения, 200,25 / 250 PLN,
69/100), browser-2 (предварительная), browser-3 (старая), browser-1 (неизвестная).
Синтетические значения служат только тестам и не публикуются как реальные рейсы.
