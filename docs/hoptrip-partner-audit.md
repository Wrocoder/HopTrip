# HT-05: аудит партнёрских переходов — 2026-10-11

## Подтверждённые факты

| Интеграция | Параметры | Переход |
| --- | --- | --- |
| Aviasales | Исходный /search от источника; маршрут, даты, пассажиры и ticket-поля сохраняются; currency=pln. Один tp.media/r: marker=779959, trs=577569, sub_id=hoptrip_web_deal. | Живой тест: HopTrip 307 → tp.media 302 → aviasales.com 200 |
| Stay22 | /allez/roam, aid=hoptrip, address, checkin/checkout ISO, adults из формы, campaign=hoptrip_accommodation, lang=pl, currency=PLN. | Локальная форма и popup проверены; живой fetch и Edge вернули 403 Blocked. Конечная страница не подтверждена |
| Tiqets | Проверенные ссылки продукта; tpx.gr либо один tp.media с marker=779959, trs=577569, campaign_id=89, sub_id=hoptrip_attractions для длинных ссылок. | Живой пример tiqets.tpx.gr/JikjB3NX 302 → Tiqets Casa Batlló Blue p973672 200 |

Пример Aviasales взят из актуального публичного API: flight-2124-2026-10-26,
POZ → MIL, 26–28 октября 2026. Конечный путь /search/POZ2610MIL28101 сохранился,
валюта pln, tracking marker присутствует. MIL — код города, не обещание конкретного
аэропорта. HTTP 200 не подтверждает доступность тарифа или цену покупки. Переданная
expected_price — сохранённая цена источника; на интерфейсе уже есть предупреждение.
Локальный тест adapter дополнительно проверяет обновление изменённых поисков,
отклонение неверного marker/project/sub_id/target и очистку устаревшего URL при сбое.

У Tiqets подтверждён конкретный продукт и присутствие partner=travelpayouts.com,
а также tracking-параметров. Сгенерированные ID клика здесь не сохраняются.
Даты, число посетителей, язык и валюту выбирают у Tiqets: существующие ссылки
не передают фильтры авиапоиска и не обещают билеты на даты поездки. Короткая ссылка
разрешилась на /en/; польская локаль для неё не заявляется.

Stay22 Roam выбирает конечного продавца динамически. Поля PLN/pl передаются,
но одинаковое применение всеми продавцами не подтверждено. Историческая официальная
документация ограничивает currency ссылками Booking.com. Не выдавать параметр URL
за гарантированную валюту конечного сайта. Геокодирование address проверяется вручную.
Гости — только взрослые из формы; детей и комнаты пользователь добавляет у продавца.
Отсутствующая дата выезда/неправильный диапазон не создаёт кнопку перехода.

## Изменения

API компонента отдаёт partner_name из выбранной партнёрской программы, а не имя
агрегатора по догадке. Кнопка показывает «Sprawdź lot — <partner_name>»; при
отсутствующем названии остаётся нейтральная подпись. Неактивная/неодобренная программа
не получает redirect_path; UI сообщает о недоступности. Disclosure сохранён,
точная цена после перехода не обещается.

Drive не загружается на /deals, /info и /alerts. При переходе туда из страницы,
где скрипт уже загружен, документ перезагружается без Drive. Это исключает независимое
переписывание готовых партнёрских ссылок на этих страницах. На других страницах
сохраняются существующие настройки и согласие. Локальная политика проверена unit;
реальный сторонний скрипт не запускался в тестах (его настройки кабинета не менялись).
В тестовой среде Drive глобально отключён; E2E проверяет отсутствие скрипта,
но не имитирует его внутренний алгоритм переписывания.

## Проверка в кабинетах — без тестовой покупки

1. Войти в Travelpayouts в проект HopTrip; сверить marker 779959 / project 577569,
   активность программ Aviasales и Tiqets и одобренный сайт. Не публиковать токены.
2. В отчёте кликов выбрать период и часовой пояс теста, программу и placement:
   hoptrip_web_deal для Aviasales; hoptrip_attractions для длинных Tiqets ссылок.
   Для коротких ссылок сверить их назначение в менеджере ссылок. Не ожидать,
   что placement автоматически станет индивидуальным ID бронирования.
3. В Stay22 Hub сверить AID hoptrip, найти клики по campaign hoptrip_accommodation;
   открыть ссылку выше один раз в обычном браузере, записать продавца, город,
   даты, гостей, фактические язык/валюту. Не обходить блокировку автоматизацией.
4. Учитывать задержку отчётов, часовой пояс и фильтрацию диагностических кликов.
   Отсутствие строки сразу после перехода не доказывает потерю комиссии.
5. Продажи проверять только по будущим реальным бронированиям в отчётах транзакций:
   статус pending/confirmed/cancelled, сумму и валюту комиссии, программу и
   доступные метки атрибуции. Не совершать покупку ради проверки. Сверять с импортом
   AffiliateConversion, не превращать PARTNER_CLICK в продажу.

Во время этого аудита выполнены диагностические HTTP-переходы Aviasales/Tiqets
и две неуспешные попытки Stay22; они могут попасть в отчёты как тестовые клики.
Доступа к кабинетам не было. **Начисление комиссии не подтверждено.**
