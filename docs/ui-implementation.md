# Реализация UI HopTrip

Дата: 2026-09-21. Основание: [UI.md](UI.md).

Обновлены главная, каталог, страницы аэропортов/направлений, предложение,
информационные статьи, навигация, footer и состояния загрузки/ошибки/пустого каталога.
Сохранены URL, тексты статей, фильтры, пагинация, условия доступности предложения,
партнёрские переходы, события аналитики и правила индексации.

## Визуальная система

| Требование | Реализация |
| --- | --- |
| Палитра | Все 12 цветов из UI.md — CSS variables в `apps/web/src/app/globals.css` |
| Типографика | Локальные variable fonts Fraunces и DM Sans; `next/font/local`, `display:swap` |
| Иерархия | Асимметричная главная, тёмно-зелёный основной CTA, направление и цена в карточках |
| Поверхности | Контейнер до 1160 px; радиусы 24/16/9 px, тонкие границы, мягкие тени |
| Акценты | Жёлтые оценки/основное действие, светлый коралловый блок ограничения стоимости |
| Детали | Статусная точка, круглые стрелки, тонкие дуги на тёмных карточках, SVG-зерно с opacity .05 |
| Формы | Сетка полей, высота контролов 48 px, размер текста 16 px, отдельный focus |
| Телефон | Одна колонка, радиус 18 px, перенос навигации; блок перехода к партнёру перед подробным разбором цены |
| Движение | Переходы 220 ms, смещение 2–3 px, отключение анимации/смещения при reduced-motion |
| Клавиатура | Видимый focus, ссылка пропуска навигации, именованные области и формы |
| Дополнительные фильтры | Даты и длительность внутри details; автоматическое раскрытие применённых условий |
| Применённые условия | Метки со снятием одного фильтра, общий сброс, возврат на первую страницу |
| Текущий раздел | Выделение пункта меню и aria-current для каталога, маршрутов, предложений и статей |

Для читаемого мелкого текста используется `#4E625D`, а не светлый `#81908A`.
На коралловом фоне используется тёмный текст: белый мелкий текст не даёт нужной
читаемости. Коралловый акцент сохранён в выделенном информационном блоке.
Новые вкладки, фильтры-пресеты и шкалы не вводились: существующие функции не требуют их.
Метки показывают уже применённые параметры URL, а не предустановленные наборы условий.

Дополнение: основные поля и кнопка применения остаются сверху; даты/длительность
раскрываются по запросу либо автоматически при заданных параметрах и ошибке валидации.
Снятие метки сохраняет остальные условия и сбрасывает offset. Общий сброс ведёт на `/deals`.
Форма получает новый key при смене URL: несохранённые правки не смешиваются с применёнными
условиями. Проверен возврат браузером назад. Отправка остаётся обычным GET.
Текущий адрес меню отмечается `aria-current="page"`, вложенная страница — `location`.

Шрифты получены из официального репозитория Google Fonts:
[Fraunces](https://github.com/google/fonts/tree/main/ofl/fraunces) и
[DM Sans](https://github.com/google/fonts/tree/main/ofl/dmsans).
Файлы и исходные SIL OFL лицензии лежат в `apps/web/src/app/fonts/`.
Сборка и браузер загружают шрифты из проекта, не из Google Fonts.

## Проверка

Итог 2026-09-21: lint и typecheck прошли; production build Linux Docker прошёл;
полный Playwright-прогон — **18 passed** (12 функциональных + 6 UI, desktop/mobile Edge).
После сборки локальная главная возвращает HTTP 200, `/health/ready` — `ready`.
Проверено наличие ссылок на локальные шрифты в собранной странице.

Первый дополнительный UI-тест встретил одновременно loading и основную страницу
при потоковом рендеринге Next.js. В тесте добавлено ожидание завершения loading;
последующий полный прогон прошёл. Основные пользовательские сценарии изменений не потребовали.

Браузерные сценарии используют отдельную fixture-БД, без реальных предложений
и обращения к партнёрам. Цены на тестовых скриншотах не публикуются в рабочем каталоге.
`apps/web/tests/ui.spec.ts` проверяет отсутствие горизонтальной прокрутки,
загрузку обоих шрифтов, skip-link, reduced-motion и отправку фильтра на ширине 320 px.
Создаются скриншоты главной, каталога, предложения, статьи и пустого состояния
в игнорируемом `apps/web/test-results/` для desktop/mobile.

Проверки доступности покрывают перечисленные сценарии, но не заменяют полноценную
проверку всеми screen reader/browser комбинациями. Safari/WebKit отдельно не проверялся.

Посмотреть обновлённый интерфейс: http://localhost:58080.
Без внешних цен этот стенд показывает настоящий пустой каталог и информационные страницы.
