# HT-17 — техническая основа SEO

Статус: DONE. Аудит 2026-10-12 выполнен на текущем локальном коде с API-фикстурами.
Production не обновлялся; это проверка реализации, а не отчёт Search Console.

## Политика индексирования

| Тип страницы | Индексация | Canonical | Sitemap |
| --- | --- | --- | --- |
| Главная, /info | Разрешена | Свой постоянный URL | Да |
| /deals без фильтров, /from/WRO, /destinations/milan | Разрешена; проверенные посадочные с самостоятельным текстом | Свой URL | Да |
| Опубликованные материалы /info/* | Разрешена | Свой URL | Да |
| Произвольные фильтры, сортировка и пагинация /deals?… | noindex, follow | Свой нормализованный URL с поддерживаемыми параметрами | Нет |
| Другие справочные аэропорты/направления | noindex, follow до редакционной подготовки | Свой URL | Нет |
| Временные предложения /deals/:slug | noindex, follow | Свой URL, пока предложение существует | Нет |
| /saved, /trip, /alerts, /alerts/confirm, /alerts/manage | noindex, nofollow | Свой адрес; /trip без данных плана, подписки без токенов | Нет |
| Служебные/неопубликованные материалы | noindex, follow | Свой URL | Нет |
| Отсутствующие/истёкшие предложения и неизвестные адреса | noindex | Не указывают главную как дубликат | Нет |

robots.txt разрешает обход сайта, кроме /api/ и /go/. Страницы с noindex
не закрываются через Disallow: робот должен прочитать директиву в HTML.
Адрес sitemap абсолютный, из NEXT_PUBLIC_SITE_URL. Трекинговые параметры
не создают самостоятельные canonical. /from/wro сохраняет совместимость,
canonical указывает /from/WRO. Действующие URL не переименовывались.

## Исправления

У страницы регистрации и страниц подтверждения/управления подпиской были
унаследованные canonical главной. Заданы /alerts, /alerts/confirm и /alerts/manage.
Canonical / перенесён из общего layout в page.tsx главной, чтобы новые страницы
и ошибки не объявлялись копиями главной по умолчанию.

Генерация метаданных предложения, аэропорта и направления теперь вызывает
notFound при отсутствии записи, не формируя ссылку на несуществующий preview.
Для экрана not-found явно заданы noindex и отсутствующий canonical/social metadata.

Истёкшие предложения исключаются API из актуального каталога. Они не показывают
старую цену как доступную и не содержат ссылки на покупку. На этой стадии нет
полезного архивного содержимого, ради которого стоило бы индексировать карточку.
Сохранённый пользователем план /trip остаётся самостоятельным noindex-снимком
с оговорками об актуальности; он не превращает истёкшую оферту в действующую.

## HTTP и потоковый рендеринг

Next.js может уже отправить HTTP 200 через loading/Suspense до определения
отсутствующей записи. В таком ответе проверяется обязательный noindex в HTML;
цена и переход к покупке отсутствуют. Неизвестный верхнеуровневый маршрут
возвращает 404. Все фактические статусы сохраняются в JSON-аудите.
Мы не выдаём потоковый 200 за HTTP 404. Поисковик может классифицировать его
как soft 404; отключение потокового рендеринга всего сайта ради статуса не вводилось.

HTML проверялся в Chromium с JavaScript выключенным и User-Agent Twitterbot.
При streaming серверный HTML может содержать скрытую часть страницы и fallback;
наличие текста в HTML не означает, что браузер без JS уже покажет конечный экран.
Отдельный контекст с JS проверяет видимый экран ошибки без цены и кнопки покупки.

tests/technical-seo.spec.ts обходит все адреса, реально опубликованные sitemap:
HTTP 200, уникальные непустые title/description, lang=pl, один h1, серверный HTML,

страницы поиска, пагинация, подписки, сохранённый план, неизвестные и истёкшие записи.
Ссылки из справочников на реальные рейсы/аэропорты вне тестового каталога этим
локальным обходом не подтверждаются. Внешние партнёрские сайты не обходились.

Существующие catalog-seo.spec.ts проверяют индексируемые посадочные, параметры
canonical и реальные PNG-превью 1200×630, включая 404 для отсутствующих изображений.

изменений метаданных служебных страниц; используется только тестовая почта.

catalog-seo.spec.ts и alerts.spec.ts с --project=desktop. HOPTRIP_TEST_PYTHON
указывает на SDK проекта; в этой среде PLAYWRIGHT_CHANNEL=msedge.

Нет данных Search Console об обходе, индексации или позициях. Изменения не
