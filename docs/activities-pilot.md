## Поведение и поддержка

- Реестр: `apps/web/src/lib/destination-activities.ts`. Точное сопоставление slug
  назначения; неизвестный город не получает чужие карточки. Без отдельных запросов
  к поставщику при просмотре и без клиентского JavaScript для блока.
- Короткие самостоятельные описания на польском; без копирования изображений,
  цен, рейтингов и обещаний свободных мест. Цена перелёта не меняется.
- Исходные ссылки (`href`) — прямые HTTPS на конкретные продукты. Проверенные
  ссылки владельца добавляются отдельно как `affiliateHref`: у таких карточек
  есть раскрытие комиссии и `rel="sponsored noopener noreferrer"`.
  Не создавались фиктивные APPROVED-программы.
- Нет новых cookies, виджетов, аналитических событий или запросов к Tiqets до
  перехода пользователя. Ticketmaster и его feature flag не задействованы.
- Перед изменением продукта проверить итоговый URL, город, доступность самого
  продукта и состав билета, обновить `checkedAt`. При снятии с продажи удалить
  карточку. Рекомендуемый следующий ручной пересмотр: 2026-11-03; автоматического
  обновления каталога пока нет.

Выпуск затрагивает только web: реестр, компонент, его CSS module и страницу перелёта.
Локальные изменения афиши Ticketmaster в пакет публикации не включаются.
