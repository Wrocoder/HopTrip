# Подборки в статьях и аналитика переходов

2026-10-03. Блок «Muzea i atrakcje» добавлен в 21 опубликованный гайд по 18 городам.
Используется тот же каталог, что на страницах перелётов. Привязки перечислены
в `apps/web/src/lib/guide-destinations.ts`; общие статьи и гайды аэропортов вылета
не получают случайную подборку. Для Амстердама пока нет проверенной подборки.
Расширенные привязки также включают существующий блок перелётов и обратные ссылки
на статьи для этих городов.

Новый тип события: `ACTIVITY_CLICK`. Отправляется только с действующим согласием
на аналитику HopTrip. Отказ/отзыв согласия не мешает переходу по обычной ссылке.
Событие содержит город, ID карточки, путь исходной страницы без query-параметров,
тип ссылки `affiliate`/`official`, существующий псевдонимный ID сессии и контекст кампании.
ID объекта входит в ключ подавления двойных кликов в течение секунды. На сервере
повтор одного event_id не создаёт вторую запись. Поддерживаются обычный клик,
клавиатурная активация и средняя кнопка мыши. Переходы через контекстное меню
могут не попасть в статистику. Отчёт отражает измеренные клики, не всех посетителей.

Контекст проверяется Pydantic: ограниченные длины, формат ID/slug, только пути
`/info/...` и `/deals/...`, запрет query-параметров и произвольного вида ссылки.
Произвольная metadata отбрасывается; клиент не может этим событием подтвердить покупку.
Данные используют существующую таблицу и срок хранения аналитики, миграция не нужна.

## Просмотр отчёта

Существующий защищённый endpoint `GET /api/v1/admin/analytics/summary`
с заголовком `X-Admin-Token` теперь возвращает:

- `total_activity_clicks`: все измеренные переходы по карточкам;
- `activity_clicks`: строки `city`, `activity_id`, `page`, `link_kind`, `clicks`, `sessions`.

Строки сортируются по числу кликов. `sessions` — число различных сессий в строке,
не уникальных людей; его нельзя складывать между строками как общий охват.
Параметры `start` и `end` принимают даты со временем и часовым поясом,
интервал включает start и исключает end. Без параметров — существующий период хранения.
Административный токен используется только на сервере; публичного экрана статистики нет.

Пример строки (иллюстрация, не реальные данные):
`{"city":"milan","activity_id":"tiqets-1111408","page":"/info/milan-weekend","link_kind":"affiliate","clicks":3,"sessions":2}`.

Покупки и комиссия остаются в отдельных полях отчёта. Нажатия карточек не добавляются
в `confirmed_bookings` или счётчик редиректов на перелёты `total_affiliate_clicks`.
Подтверждение продаж Tiqets по каждой карточке этим выпуском не реализовано.
