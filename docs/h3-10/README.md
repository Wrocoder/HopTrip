## Аудит и минимальный объём

До изменений все четыре `/destinations` routes возвращали 404, navigation вела на home hash, а HomePage выводила весь API registry: до трёх editorial picture cards и неограниченный список остальных городов. [Baseline](baseline.json), [лог](baseline.txt), [инвентарь](baseline-inventory.json): один успешный production browser audit до правок, 244 sitemap URLs и три направления в обычной синтетической fixture. Большая мобильная задержка на этой маленькой fixture не измерялась; подтверждены структура неограниченного списка и отсутствие directory, а не production usability/CWV defect.

Добавлен `/destinations` и EN/RU/UK wrappers. Существующий validated getDestinations остаётся единственным реестром: без отдельной БД, pricing feed или нового API. Группы сортируются по локализованной стране и городу через Intl; неизвестная страна получает нейтральную группу. Неактивные направления исключаются. Весь список активных городов и якоря стран приходят в server HTML.

Нативная GET-форма `?q=` работает без JavaScript. Поиск использует прежние normalizeDestination и общие multilingual names/aliases/IATA, допускает частичное совпадение и не наследует лимит 12 autocomplete suggestions. Строка query однозначная, с нормализованными пробелами и ограничением 100 символов; пустое значение показывает весь каталог. Нет JS search index или скрытого обязательного клиентского шага. Сброс, Back, locale switching, пустой результат, пустой registry и недоступный API проверяются отдельно. Count означает число направлений, не число рейсов.

## Главная, навигация и SEO

На главной остаются максимум три прежние licensed editorial destination cards и видимая ссылка «Все направления»; популярность или наличие рейсов этим фото не приписываются. Три offer collections H3-09 сохранены. Главная навигация ведёт в новый каталог; old `/#home-destinations` bookmark и его aria-current=location сохранены, сама directory имеет aria-current=page. На child destination pages выбирается раздел направлений.

Общий destinationBrowseHref сохраняет прежнее правило: PL city URL остаётся `/destinations/{slug}`, переведённый Milan доступен напрямую во всех локалях, а остальные EN/RU/UK записи ведут в существующий localized `/deals?destination={slug}`. Неизданные переводы city pages не объявляются существующими. Старые slugs, query contracts, HTTP routes и reviewed indexability city pages не меняются; redirects или mass-noindex не вводятся. Все города доступны через PL directory; ссылки на прежние indexed pages сохраняются.

Новые четыре directory URL добавлены в sitemap и независимый release SEO inventory. Directory без query index/follow, с пятью reciprocal hreflang, localized title/description/OG/canonical; любые query variants noindex/follow с canonical на базовый directory URL. API failure также noindex, с existing ApiUnavailable/retry, а не ложным пустым реестром. Изображения, лицензии, consent, аналитическая taxonomy, affiliate attribution, saved/share и API/schema/БД не меняются. Production deploy и реальные внешние операции не выполняются.
