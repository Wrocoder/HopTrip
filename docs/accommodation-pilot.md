# Жильё: подготовка следующего этапа

2026-10-08: калькулятор принимает общую цену проживания для всех гостей и комнат
за весь срок. Пользователь может перенести итог с сайта бронирования без деления
на ночи. Режим «за ночь» сохранён, суммы режимов независимы; автоматически берётся
только выбранная сумма. Это не подключение поставщика и не получение живой цены.

2026-10-05. Локальная подготовка; не опубликовано. Подтверждённых ссылок
и выбранной одобренной программы жилья пока нет.

TripAccommodation подключён после цены и бронирования перелёта. Каталог
accommodation-links.ts пустой: посетители не увидят блок до подключения.
Первый вариант принимает готовые ссылки на город из кабинета партнёра,
сохраняет их без изменения и честно просит выбрать даты, гостей и комнаты
на сайте партнёра. Для ROUND_TRIP показывает даты перелёта как ориентир,
для ONE_WAY не выдумывает выезд; для поездки одним днём не обещает ночёвку.
Содержит disclosure, sponsored/noopener/noreferrer и якорь к бюджету.

Автоматическая передача города и дат ещё не реализована: требуется подтвердить
формат deep link у выбранной программы. Не добавлять checkin/checkout к
сокращённой tracking-ссылке по предположению. Дата вылета не всегда совпадает
с датой заселения; будущая форма должна позволять исправить оба дня.

## Что нужно от владельца

- Название одобренной программы, либо подача заявки для hoptrip.pl.
- Ссылка из её генератора для одного города пилота (например, Малаги).
- Документация или пример генератора с городом и датами, если он их поддерживает.

## Проверенные официальные источники

На 2026-10-05 https://www.booking.com/affiliate-program/v2/index.html
направляет новых партнёров в CJ. Регион выбирается по основной аудитории:
для Польши на https://www.cj.com/en-gb/publisher/partners/booking.com
представлен Central & Eastern Europe. Доступ HopTrip не подтверждён.
Упоминание Awin в исходном плане не следует использовать как актуальную
инструкцию регистрации без проверки конкретного кабинета.

После получения доступа: проверить ссылку и целевой город, реализовать
поддерживаемый формат дат, проверить ROUND_TRIP/ONE_WAY/однодневные поездки,
мобильную верстку и доступность, затем выпустить отдельно от Ticketmaster.
