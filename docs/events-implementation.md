# События на даты поездки: первая версия

Реализовано локально 2026-09-30. На production не публиковалось.
Коммерческие условия Ticketmaster ожидают ответа на отправленную владельцем заявку.

## Поведение

При включённой функции на странице перелёта в Милан, Стокгольм, Париж или Осло
появляется блок `Wydarzenia w terminie podróży`. Для round-trip даты подставляются
из перелёта, для one-way требуется выбрать конец пребывания. Поиск выполняется
по кнопке, не задерживает отрисовку перелёта и не вызывается при каждом просмотре.

Категории: все, музыка, спорт, культура и выставки. Последняя соответствует
категории Ticketmaster Arts & Theatre, а не гарантированно полному каталогу выставок.
Остальные выставочные продукты могут находиться в общей выдаче. Классификация
доставляется источником: например, Sports иногда включает кинопоказы.

Карточки показывают площадку, локальную дату/время, перенос/недоступность продажи,
известную цену «от» в исходной валюте или сообщение об отсутствии цены.
Неизвестное время показано явно; конкретный слот и ограничения open-ticket билетов
проверяются у продавца. Время прилёта и доезда не рассчитывается.
Билеты на события не прибавляются к стоимости перелёта и не меняют flight score.

Ссылки ведут прямо на конкретные страницы Ticketmaster/Universe, по проверенному
списку HTTPS-хостов. В первой версии нет affiliate tracking или записи событийных
кликов: монетизация и её согласование — следующий этап. Изображения не загружаются.

## API и адаптер

- `GET /api/v1/deals/{slug}/events?start_date=YYYY-MM-DD&end_date=YYYY-MM-DD&category=ALL`.
- Категории `ALL`, `MUSIC`, `SPORTS`, `CULTURE`.
- Статусы `READY`, `EMPTY`, `UNAVAILABLE`, `NEEDS_DATES`, `DISABLED`, `UNSUPPORTED`.
- 404 для недоступного/истёкшего перелёта при включённой функции; 422 для неверных
  дат и категорий. Выключенная функция возвращает DISABLED без запроса к поставщику.
- Максимальный интервал — 31 календарный день; для round-trip он должен входить
  в даты поездки. Для one-way — от даты вылета до 90 дней после неё.
- Город и страна берутся из перелёта и явной проверенной карты четырёх городов;
  строки city от клиента не принимаются. Соседние муниципалитеты не подмешиваются.
- Адаптер использует `localStartEndDateTime`, проверяет пересечение дат локально,
  исключает отмену/неизвестную дату/отложенные события, проверяет страну и часовой пояс.
- Дубли одинаковых внешних ID удаляются. Сеансы с точным совпадением названия,
  ID площадки, города, часового пояса и классификации объединяются до ограничения
  в 12 карточек. Без ID площадки объединения нет; варианты названий не склеиваются.
  Каждый сеанс сохраняет дату, время, цену, статус и ссылку. Отмена/перенос
  отражаются после обновления кеша.
- Не более двух страниц по 100 записей за поиск, до 12 карточек. Флаг `partial`
  сообщает об усечении; отсутствие результатов не объявляется отсутствием событий в городе.

## Настройки локального запуска

Настройки передаются **только API**, не `NEXT_PUBLIC_*`:

```dotenv
EVENTS_ENABLED=false
TICKETMASTER_API_KEY=
EVENTS_CACHE_SECONDS=900
EVENTS_DAILY_REQUEST_LIMIT=500
```

Для локальной проверки поставить EVENTS_ENABLED=true и передать собственный ключ
через окружение запуска API или локальный игнорируемый `.env`. Файл ключа, предоставленный
владельцем, автоматически не копируется. Значение ключа не добавлять в команды/журналы.
Для Docker Compose эти переменные прокинуты в сервис api; перезапуск с изменённым env
нужен для применения настроек. Настройки worker/web менять не требуется.

Без ключа или при EVENTS_ENABLED=false блок не появляется в выдаче DealRead:
`events_supported=false`. Включение production выполнять после подтверждения условий.

Предпросмотр без настоящих данных/ключа использует существующий браузерный стенд:

```powershell
# Из apps/web, после установки зависимостей проекта:
$env:HOPTRIP_TEST_PYTHON = (Resolve-Path '..\..\.venv\Scripts\python.exe').Path
$env:PLAYWRIGHT_CHANNEL = 'msedge'
npx playwright test tests/events.spec.ts
```

Тесты сами запускают изолированную SQLite-БД/API/web и останавливают их после проверки.
Скриншоты desktop/mobile сохраняются в `apps/web/test-results/**/events.png`.
Barcelona в этом стенде — только синтетический тестовый город, не расширение живого пилота.

## Ограничения эксплуатации

Кеш хранится в памяти одного API-процесса (128 запросов, TTL по умолчанию 15 минут).
Нет миграций, постоянного каталога, фонового импорта и изменений существующего worker.
TTL — настройка пилота, не подтверждённое Ticketmaster условие хранения.
Для нескольких API-процессов потребуются общий кеш и общий лимитер; текущие лимиты
сбрасываются при перезапуске процесса. Суммарную квоту нескольких экземпляров не гарантируют.

Исходящие запросы сериализованы с интервалом не менее 1,05 с, не более 500 за UTC-день
на процесс по умолчанию. При занятости обработчика или сбое выдаётся UNAVAILABLE,
после ошибки действует пауза 60 с. Устаревший результат после истечения TTL не показывается.
TLS проверяется через системное хранилище доверенных CA; отключения проверки нет.
Ключ скрыт в Settings и удаляется из INFO-логов httpx; ошибки источника не раскрываются клиенту.

- 22 целевых backend-теста: даты/DST, отмены, соседний город, страна, неизвестные
  цены/время, безопасные ссылки, секреты в логах, кеш/обновления/квоты и API.

- 4 целевых браузерных проверки (desktop/mobile), включая axe, отсутствие переполнения,
  разные ссылки, фильтры, пустую выдачу, ошибку источника и сохранение доступа к перелёту.
- Полный браузерный прогон: 94 passed (Edge desktop/mobile).
- Ruff, mypy, ESLint, TypeScript, 5 web unit tests и production build прошли.
- Живой запрос готового адаптера: 2026-09-30 10:49:06 UTC, Милан 14–15 октября,
  READY, 5 записей, одна страница/один запрос. Ключ не сохранён в репозитории.

Следующие этапы: ответ Ticketmaster, расширение карты городов и категорий по проверенным

событийных переходов после одобрения соответствующей программы.

## Локальная доработка 2026-10-03

- Объединены сеансы по строгому ключу выше. Поле `sessions` содержит все найденные
  варианты карточки в пределах двух страниц; верхнеуровневые поля первого сеанса
  сохранены для совместимости. `partial` продолжает учитывать оставшиеся страницы.
- Категория дополнительно проверяется после ответа поставщика. Показывается его
  конкретный `genre`, если он указан и не равен Undefined/Other. Это не автоматическая
  проверка «настоящий матч»: исходная классификация Sports может включать показы.
- У каждого сеанса, пересекающего день перелёта туда/обратно, есть предупреждение
  про время прилёта, трансфер или регистрацию. Для one-way конец выбранного пребывания
  не считается обратным рейсом. В данных перелёта нет времени прибытия; автоматической
  гарантии, что пользователь успеет на событие, нет.
- Production не обновлялся; публичное включение по-прежнему ждёт условий Ticketmaster.
- Проверки доработки: 25 backend-тестов, 6 браузерных тестов (desktop/mobile,
  включая группировку, отдельные цены/ссылки, axe и ширину экрана), TypeScript,
  ESLint, Ruff, mypy и production build прошли. Запросов к живому Ticketmaster
  при этих проверках не было.
