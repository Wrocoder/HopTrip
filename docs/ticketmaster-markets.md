# Ticketmaster: страны назначения HopTrip

Проверка 2026-10-23. Источники: публичный каталог HopTrip, все страницы текущих
предложений с вылетами из польских аэропортов и Discovery API с ключом владельца.
Результаты: [ticketmaster-markets-audit.json](ticketmaster-markets-audit.json).

## Подтверждённое состояние

- В каталоге 35 стран, включая Польшу; получено 338 текущих предложений из Польши.
- По одному запросу на страну, до трёх событий с началом после момента проверки.
  Для 20 стран API вернул события. Во всех 35 запросах HTTP 200.
- В последней проверке все полученные события в выборке имеют ссылки с Impact
  publisher ID `7853869` для 17 стран: AT, BE, CH, CY, CZ, DE, DK, ES, FI, FR,
  IE, IT, NL, NO, PL, SE, TR. Для CY получено одно событие, для остальных — по три.
- GR: две из трёх записей имеют партнёрские ссылки; у третьей поле URL отсутствует.
  Дополнительный запрос подтвердил это. События без корректного URL не должны
  показываться как предложения с переходом к покупке.
- Медиаресурс владельца: `hoptrip.pl`, ID `9029029`. Италия: программа `23899`,
  рекламный ресурс `1958975`, согласно ссылке из кабинета.
- Скриншот Affiliate IDs приложения polwroacc-App подтверждает Impact, ID `7853869`
  и 18 стран: AT, BE, CY, CZ, DK, FI, FR, GR, DE, IE, IT, NL, NO, PL, ES, SE, CH, TR.
  После скриншота владелец отдельно подтвердил добавление United Kingdom (GB).
  В последней выборке GB ожидаемое отслеживание пока не появилось.
  Более поздняя проверка адаптера на датах реальной поездки в Лондон подтвердила
  7 подходящих событий с tracking: [снимок](ticketmaster-integration-smoke.json).
  Estonia отсутствует в доступном списке, по подтверждению владельца.
- Сразу после сохранения отслеживание было только у IT; при следующем замере
  оно появилось ещё у девяти стран. Причина задержки не установлена.
  Теперь ссылки подтверждены для всех 18 первоначально сохранённых стран
  (с указанным ограничением для GR). Для GB нужна последующая проверка;
  не считать его отслеживание подтверждённым по одному факту сохранения профиля.
- Проверка не меняла сайт, сервер или профиль Ticketmaster; переходы по партнёрским
  ссылкам не выполнялись. Комиссии, зачисление покупок и договоры рынков не проверены.

## Повторная проверка

После проверки вкладки Affiliate IDs приложения и применения настроек выполнить из корня проекта:

```powershell
./scripts/check-ticketmaster-markets.ps1
```

Ключ читается из `~/.hoptrip/ticketmaster.txt`; другой файл задаётся через `-KeyPath`.
Скрипт сохраняет только агрегаты и хосты ссылок, без ключа, полных URL и содержимого
событий. Между запросами пауза 1,1 секунды; при 401/403/429 запросы Ticketmaster
прекращаются. В отчёте оставшиеся страны получают NOT_CHECKED.

TRACKED_SAMPLE означает наличие ожидаемого publisher ID во всех проверенных ссылках,
а не гарантию комиссии или полного покрытия городов. NO_TRACKING_IN_SAMPLE требует
проверки настроек профиля; PARTIALLY_TRACKED_SAMPLE — проверки конкретных источников.

## Реализация сайта

Код событий из feature/ticketmaster перенесён и расширен локально в текущем приложении:
[отчёт о реализации](ticketmaster-integration.md). Добавлен поиск для всех 70 городов
каталога в подключённых странах и проверки дат/расписания, географии, статуса и ссылок.
Доступность событий на уровне страны не означает наличие событий в каждом городе.
Не использовать итальянскую/американскую программу для ссылок других рынков.
Production-включение ещё не выполнено.
