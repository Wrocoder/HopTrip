# V4-10 — страницы направлений и SEO

Выполнение 2026-11-08 после локального завершения V4-05 и V4-09. Работа ограничена V4-10; V4-11 не начинается.

## Что изменено

**Сбой загрузки цен больше не скрывает доступный путеводитель города.** Раньше общий `try/catch` объединял запросы направлений и перелётов: ошибка второго запроса превращала всю страницу в сообщение недоступности и меняла её metadata. Теперь состояния разделены:

| Ответ | Поведение |
|---|---|
| Реестр городов недоступен | Страница ошибки, `noindex`; город не придумывается. |
| Города нет в успешно загруженном реестре | Существующий `notFound`, без искусственной страницы. |
| Перелёты успешно загружены, список пуст | Честное сообщение об отсутствии наблюдений; материалы о городе доступны. |
| Запрос перелётов завершился ошибкой | Ошибка внутри блока перелётов; редакционный контент, поиск и независимый блок альтернатив сохраняются. Обычная редакционная SEO-политика страницы остаётся прежней. |
| Перелёты есть | Существующие карточки и порядок выдачи сохранены. |

В планировании **17 направлений** общий совет об аэропорте заменён кратким вступлением из уже опубликованного путеводителя с прямой ссылкой на него. Текст берётся из существующего PL/EN/RU/UK-перевода; новые сведения о тарифах, расписании или расстояниях не добавлялись. Полные статьи не копируются на страницы городов. Для остальных направлений остаётся общий совет без выдуманного наполнения.

Страница Reykjavík теперь ссылается на готовый материал об Исландии, содержащий варианты поездок из столицы и ограничения короткого маршрута. Это региональный материал: обратная классификация как статьи только об одном городе не включается. Существующий блок экскурсий Reykjavík остаётся единственным.

У Амстердама найден готовый аэропортовый материал, но самого города нет среди 69 seed-направлений. Новая привязка, создающая обратную ссылку на незарегистрированный город, не включена. Seed-каталог и опубликованные маршруты не расширялись.

## Инвентарь и решения

[Полный инвентарь](inventory.json) содержит каждое из **69 seed-направлений**, коды аэропортов, материалы, языковую доступность, цели ссылок каталога и текущую политику. Это инвентарь репозитория; количества предложений и фактической индексации оставлены неизвестными.

| Категория | До | После | Решение |
|---|---:|---:|---|
| Есть связанные редакционные материалы | 18 | 19 | Переиспользовать готовое содержание и ссылки; не открывать массовую индексацию. |
| Общий шаблон без материала об этом направлении | 51 | 50 | Сохранить `noindex` и поиск; наполнение требует отдельного обоснования и источников. |
| Краткий блок прибытия из аэропортового путеводителя | 0 | 17 | Один существующий вводный абзац и ссылка, с локализацией. |
| Страницы города с разрешённой индексацией | Milan × 4 языка | Без изменений | Решение существующего редакционного registry, не подтверждение Google. |

Все **69 польских URL + 3 языковых URL Milan** сохранены. Rome и остальные неподготовленные к индексации городские страницы остаются `noindex`; языковой каталог ведёт к локализованному поиску там, где переведённая страница города не опубликована. Отсутствие текущей наблюдаемой цены не становится критерием индексации.

`catalog-pages`, `growth-pages`, routing, переведённые landing metadata, sitemap и robots не изменены; контрольные суммы до/после записаны в инвентаре и итоговой проверке. Даты `reviewedAt`, исходные материалы и их переводы не редактировались.

## Проверки

Итоговые результаты и история browser-прогонов — в [verification.json](verification.json). Полные browser reports сохранены рядом с отчётом; локальные рабочие журналы: `.cache/v4-10-*`.

- Исходные профильные Node: **18 PASS**. Новые проверки: недоступный реестр, неизвестный город, пустая/ошибочная выдача, сохранение наблюдений, региональная связь и точность локализованных вступлений для всего seed-каталога.
- Профильный набор на финальном коде: **24 PASS**. Полный набор Node: **377 PASS**, без skipped. ESLint, production build с TypeScript и отдельный финальный `tsc --noEmit`: **PASS**. Журналы: [Node](node.txt), [focused](focused.txt), [ESLint](eslint.txt), [build](build.txt), [типы](types.txt).
- Первый запуск browser остановился при сборе нового spec из-за `import.meta` в CommonJS-контексте Playwright; исправлен путь тестового файла, приложение не менялось.
- Первый выполненный browser-run: **34 PASS / 2 FAIL**. Оба сбоя — новая проверка неизвестного URL ожидала единственный robots-тег, тогда как Next выводит два согласованных `noindex`. Теперь проверяются все выведенные директивы.
- Финальный прогон: **42/42 PASS**, без skipped/flaky. В обоих проектах проверены все **69 seed-страниц без JS** и все **248 URL sitemap**: robots, canonical/hreflang, уникальность metadata и достижимость редакционных ссылок. Также прошли приёмка направлений/альтернатив, локализованный отказ цен и сохранность единственного блока Reykjavík. Артефакты: [seed desktop](seed-ssr-desktop.json), [seed mobile](seed-ssr-mobile.json), [sitemap desktop](sitemap-desktop.json), [sitemap mobile](sitemap-mobile.json).

В сценариях направлений используются 4 локали, ширины 320/375/390/768/1440, scoped axe и обычная клавиатурная навигация. Классификация seed-страниц проверяется в локальном API-fixture с подстановкой групп по три города. Это не production-проверка наличия рейсов. Платные интеграции и реальные уведомления не активируются.

Вручную просмотрены [RU-планирование на 320 px](arrival-ru-320.png) и [ссылка Reykjavík на 320 px](reykjavik-320.png). После тестов локальные серверы остановлены, `next-env.d.ts` восстановлен из снимка до задачи. Проверены контрольные суммы SEO-политик и сохранность остальных исходников V4-09, ссылки отчёта, пробелы и scoped `git diff --check`.

## Search Console и границы

В предоставленном [реестре URL Inspection](../seo-growth-20261107/indexing/review.csv) **15 из 15 строк PENDING**, результатов Google нет. Среди доступных подключённых инструментов GSC-инструмента не обнаружено. Нового сопоставимого экспорта после переобхода в материалах этой задачи нет. Старый публичный HTTP snapshot не выдаётся за новый результат Google.

Индексацию не расширяли. Подтверждение Google canonical/index status и измерение эффекта после переобхода остаются внешним продолжением по [существующей методике](../SEO_MEASUREMENT_FOLLOWUP.md). Локальные разработки и тесты V4-10 от этих данных не зависят.

Production/deploy, GSC mutation, запрос индексирования, базы production и реальные отправки не выполнялись. Новых зависимостей, API-контрактов и миграций нет. Повторная проверка актуальности внешних тарифов/расписаний, WebKit, реальные устройства, ручной screen reader и field CWV не заявляются. Отдельный pytest/PG не выполнялся: API-код и fixtures не менялись, использован настроенный Python 3.12.10 для существующего локального тестового API.
