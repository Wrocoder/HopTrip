Обновлены пять файлов: главная, site-nav, trip-budget-calculator, trip-budget
и страница предложения. Ticketmaster и блоки трансферов в выпуск не включены.

Compose production + domain с `--no-deps --no-build`; API/worker/БД не обновлялись.
API readiness после публикации: ready.

Проверка в Edge на https://hoptrip.pl: вход с главной и меню, расчёт 1600/800 PLN,
цена 219 PLN и длительность реального ROUND_TRIP flight-1682-2026-11-09,
неполный бюджет при неизвестных расходах, axe формы и меню без нарушений,
нет горизонтального переполнения на 320/390/1280 px или ошибок JavaScript.
В первых 100 предложениях ONE_WAY не найден; этот сценарий проверен локально
модульным тестом, но не на живом предложении.
Отчёт: `budget-production-check-2026-10-05.json`.
Повтор проверки: из apps/web `node scripts/audit-budget.mjs https://hoptrip.pl`.
Проверка задаёт отказ от аналитики и маркетинга, партнёрские ссылки не открывает.

Откат: `hoptrip-web:before-budget-visible-20261005`, исходники
`/opt/hoptrip/backups/web-source-before-budget-visible-20261005.tar`.
Для отката восстановить пять файлов из архива, присвоить сохранённому образу
тег hoptrip-web:latest и пересоздать только web тем же Compose с
`--no-deps --no-build`. Выпускной архив содержит только эти пять файлов:
`/tmp/hoptrip-budget-release-20261005.tar`.

Калькулятор доступен в меню, на главной и рядом с ценой перелёта.
На странице предложения расчёт встроен: подставляется flight_price_pln,
начальная группа — один человек. Для ROUND_TRIP ночи считаются по датам,
дни расходов — ночи + 1. Для ONE_WAY остаются явно обозначенные примерные
значения 2 ночи / 3 дня; пользователь добавляет возвратный билет самостоятельно.
Неизвестные расходы остаются пустыми. Сброс очищает расчёт до общих значений
калькулятора; введённые данные не сохраняются после обновления страницы.

## Трансферы: опубликованы 2026-10-05

Компонент AirportTransfer подключён после разделов статей malaga-airport,
alicante-airport и prague-airport. Каталог apps/web/src/lib/airport-transfers.ts
содержит три ссылки, предоставленные владельцем в переписке. Существующие
инструкции общественного транспорта сохранены. API и виджеты не подключены.

Ссылки: Малага https://tpx.gr/mTuIViB0, Аликанте https://tpx.gr/gtneOoSO,
Прага https://tpx.gr/YbMCDRFd. Проверка редиректов подтвердила соответствующие
welcomepickups.com/{malaga,alicante,prague}/airport-taxi/ с aff_track_id,
содержащим marker 779959, и utm_source=travelpayouts. Конечные страницы
ответили автоматическому клиенту HTTP 403: полный процесс бронирования
не проверен. Редиректы не доказывают регистрацию продажи или выплату комиссии.
При проверке ссылок могли зарегистрироваться технические партнёрские переходы.

Записи airportTransfers содержат city, affiliateHref и verifiedAt.
Компонент показывает пометку о комиссии и rel="sponsored noopener noreferrer".
Удаление записи отключает соответствующий блок. Конверсии подтверждаются
отчётами партнёра; отдельный сбор кликов пока не реализован.

Выпуск содержит три файла: info/[slug]/page.tsx, airport-transfer.tsx,
airport-transfers.ts. TypeScript, ESLint и production ARM64 build прошли.
Обновлён только web. API readiness: ready. Браузер проверил все три страницы:
HTTP 200, точные href, target/rel, пометку комиссии, axe без нарушений,
отсутствие переполнения на 320/390/1280 px, ошибок JS и обращений к партнёру
при загрузке. На WRO блок отсутствует. Мобильный скриншот просмотрен.
Отчёт: `transfers-production-check-2026-10-05.json`.
Повтор проверки: из apps/web `node scripts/audit-transfers.mjs https://hoptrip.pl`.

Откат: image `hoptrip-web:before-transfers-20261005`; исходная страница info
в `/opt/hoptrip/backups/web-source-before-transfers-20261005.tar`.
Восстановить страницу, вернуть сохранённому image тег hoptrip-web:latest
и пересоздать только web через production + domain Compose с
`--no-deps --no-build`. Новые неиспользуемые файлы компонента и каталога можно
оставить на диске. Выпуск: `/tmp/hoptrip-transfers-release-20261005.tar`.
