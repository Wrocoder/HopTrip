# HT-07 — первый экран главной

Локальная проверка 2026-10-11. Одинаковые Playwright fixtures, Edge,
viewport 1440×900 и 390×844. В мобильном профиле deviceScaleFactor=3:
изображение содержит больше физических пикселей, размеры окна указаны в CSS px.
Сравнение до HT-07 и после; production не менялся.

## Измерение

Положение верхней границы первой карточки относительно начала документа.
Панель приватности закрыта через «Odrzuć opcjonalne», страница прокручена к началу.

| Окно | До | После | Сокращение расстояния |
| --- | ---: | ---: | ---: |
| Desktop 1440×900 | 1430,89 px | 602,70 px | 828,19 px / 57,9% |
| Mobile 390×844 | 1744,92 px | 814,06 px | 930,86 px / 53,3% |

На десктопе первая строка предложений видна сразу. На телефоне видны заголовок
выдачи и начало первой карточки; для цены нужен скролл. При открытой панели
приватности контент сдвигается вниз и остаётся доступным прокруткой:
панель не наложена поверх формы или кнопок. Это изменение геометрии страницы,
а не измеренный рост конверсии или скорости загрузки.

## Что изменилось

Главная: короткое описание → поиск по аэропорту, направлению и бюджету →
быстрые фильтры → предложения WRO → калькулятор и справочники.
Вроцлав явно выбран как стартовый аэропорт аудитории промпта; другие аэропорты
можно выбрать в форме, после отправки открывается отфильтрованная /deals.
Начальные предложения получаются с origin=WRO, а не только подписаны этим кодом.
Список всех аэропортов и ссылка на общую выдачу сохранены.

Даты и ночи раскрываются в «Daty i długość pobytu». Правила пресетов доступны
в «Zasady szybkich filtrów» и связаны с кнопками через aria-describedby.
Форма сохраняет валидацию и передачу параметров. На главной добавлено уже
существующее поле направления с польскими подсказками.

Панель приватности находится перед основным содержимым в потоке документа.
Оба независимых переключателя, отказ, принятие всех и сохранение выбора остаются
видимыми. Подробности о сроке хранения, идентификаторе сессии, Drive и его
правилах раскрываются отдельно. Кнопка настроек остаётся в футере.
Сохранение выбора не прокручивает страницу к футеру.

Фотографии, подписка и новые внешние запросы не добавлены. Цвета, шрифты,
партнёрские обозначения и сведения о составе цены сохранены.

## Повторная проверка

С SDK Python проекта в HOPTRIP_TEST_PYTHON и PLAYWRIGHT_CHANNEL=msedge:

- npm --prefix apps/web run test:e2e -- home-layout.spec.ts trip-filters.spec.ts consent.spec.ts ui.spec.ts
- npm --prefix apps/web run lint
- npm --prefix apps/web run build

home-layout проверяет отсутствие перекрытия панелью, начальные выключенные
согласия, высоту первой карточки, подсказку WRO, раскрытие правил и поиск
Mediolan с бюджетом. Для сохранения новой пары PNG/JSON в docs задать
HOPTRIP_HOME_PHASE=after. Без переменной артефакты пишутся в test-results.
Существующие «before» получены до изменений, повторный запуск текущего кода
не воспроизводит прежний интерфейс.
