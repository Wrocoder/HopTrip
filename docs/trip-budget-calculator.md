# Калькулятор бюджета поездки

Локальное обновление 2026-10-08: добавлен выбор цены жилья за ночь или за весь
срок проживания всей группы. Оба поля сохраняют независимые значения при
переключении; рассчитывается только выбранный вариант. Итоговая цена за весь срок
суммируется в грошах без деления на ночи и повторного умножения на гостей.
Изменение дат/числа гостей не пересчитывает цену поставщика: интерфейс напоминает
проверить её заново. Сброс очищает оба поля. Не опубликовано.
Проверки: 17 unit-тестов web, 8 браузерных сценариев бюджета desktop/mobile,
включая axe и ширину 320 px; TypeScript, ESLint и production-сборка прошли.

Обновление 2026-10-05: калькулятор доступен с главной и меню, встроен в страницу
предложения с подстановкой стоимости перелёта и дат ROUND_TRIP.
Опубликовано; [проверки и откат](trip-planning-pilot.md).
Ниже — описание первоначального выпуска 3 октября.

Реализация 2026-10-03: `/info/trip-budget#calculator`. Ссылки со страниц перелётов
ведут к калькулятору; цены из предложения автоматически не подставляются.

Пользователь задаёт количество людей (1–50), ночей (0–365) и дней расходов
(1–365). Все суммы в PLN, допускаются точка и запятая с двумя десятичными знаками.

- Перелёт за все нужные сегменты, багаж и аттракции: на человека за поездку.
- Ночлег: за ночь на всю группу, умножается только на ночи.
- Трансферы и прочие расходы/резерв: на всю группу за поездку.
- Питание и ежедневные расходы: на человека в день.

Суммирование выполняется в целых грошах. Стоимость на человека — равное деление
с округлением до гроша. Цены на человека предполагаются одинаковыми для группы.
Пустое поле остаётся неизвестным, даже если известные расходы равны нулю;
явный ноль означает отсутствие отдельного расхода. Неверный ввод скрывает итог
до исправления. Итог обозначен как пользовательский план, не цена готового тура.

Данные существуют только в состоянии компонента: без сохранения, сетевых запросов,
передачи в аналитические события или записи в URL. Обновление страницы очищает ввод.
Компонент использует отдельный CSS module и существующее оформление сайта.

Проверки: 9 web unit tests (4 новых), 4 desktop/mobile E2E, axe формы,
ширина 320 px, TypeScript, ESLint и production build. Контрольный пример:
2 человека, 2 ночи, 3 дня; перелёт 300, багаж 50, ночлег 200, трансферы 100,
питание 40, аттракции 30, резерв 100 → 1600 PLN всего / 800 PLN на человека.

Пакет выпуска содержит шесть файлов, без локальной интеграции Ticketmaster.
Откат подготовлен: `hoptrip-web:before-budget-20261003` и исходники
`/opt/hoptrip/backups/web-source-before-budget-20261003.tar`.

Опубликовано 2026-10-03: пересобран и обновлён только web через Compose
с `--no-deps --no-build`. API readiness: ready. Production-проверка в Chrome:
HTTP 200, контрольный расчёт 1600/800 PLN, axe без нарушений, отсутствие
горизонтального переполнения на ширине 390 px и ссылка из реального предложения.
Мобильный скриншот формы проверен отдельно. Число URL в sitemap не меняется:
калькулятор встроен в существующую статью; описание и дата проверки обновлены.
