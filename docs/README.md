## Сохранённые служебные файлы

`article-imagery/assets.json` используется тестами, а `ui02/assets.json` — атрибуцией изображений сайта. Эти файлы и поясняющие README сохранены. Скрипты проверок, включая `aud05/prepare-e2e.ps1`, также сохранены.

Каталоги `htui02`, `htui04` и `mobile-trip-20261025` оставлены как пустые места записи результатов старых проверок; прежние изображения и отчёты из них удалены.

## История до H3

По согласованному списку удалены 1263 старых файла, включая отчёты, устаревшие планы и 395 изображений документации. Рабочие изображения сайта и текущий H3 сохранены. Ссылки на удалённые документы заменены текстовыми историческими пометками; версии ранее отслеживавшихся файлов остаются в истории Git.
