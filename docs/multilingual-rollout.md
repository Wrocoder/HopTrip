# Мультиязычность HopTrip

Обновлено: 2026-10-19. Языки: pl, ru, en, uk (не ua).
Статус: основа, самостоятельный калькулятор и форма фильтров реализованы локально. Полный перевод сайта ещё не завершён. Эти изменения не опубликованы.

## Исследование и архитектура

Next App Router, серверные страницы и клиентские формы. Общие сообщения вынесены из lib/pl.ts в i18n; совместимые экспорты сохранены. API, IATA, slug, цены, расчёты и хранилище черновиков остаются общими. Изучены локальные руководства Next по internationalization и proxy.

Язык определяется URL: польские адреса без префикса, остальные /en, /ru, /uk. Нет перенаправлений по IP или языку браузера. Proxy перезаписывает служебный заголовок языка; посетитель не может изменить язык польского URL своим заголовком. Корневой layout читает заголовок и формирует html lang и контекст запроса. Это делает ранее статические страницы /info и /saved динамическими; влияние на production TTFB пока не измерено.

## Реализовано

- Типизированные общие словари, форматтеры дат, PLN и ночей на четырёх языках. Валюта не конвертируется, неизвестные значения не становятся нулями.
- Реальные страницы /en/info/trip-budget, /ru/info/trip-budget, /uk/info/trip-budget. Польская /info/trip-budget сохраняет адрес и руководство.
- Общий калькулятор: поля, подсказки, ошибки, результаты, детализация, сохранение/восстановление черновика и сообщения об изменениях плана переведены. Расчёты и модель путешественников прежние.
- Переключатель названиями языков только на готовой странице. Полная навигация обновляет серверный html lang; query, hash, бюджет и согласия сохраняются.
- Навигация, footer и панель согласий переведены. Ссылки на непереведённые разделы помечены как польские. Юридические документы пока доступны на польском.
- Canonical на собственный URL, взаимные hreflang для четырёх языков и x-default, три новых адреса в sitemap без выдуманного lastmod. Неготовые /en/deals и неподдерживаемые языки возвращают 404.
- Аналитика распознаёт языковые страницы бюджета как budget; исключения Drive сохранены. Согласие требуется до отправки событий, отзыв согласия прекращает отправку.
- Справочные тарифы транспорта и подробное руководство остаются по явно обозначенной польской ссылке; они не выдаются за переведённый материал.

Проверка редакционного индекса/sitemap: mobile прошёл; desktop сначала превысил 5s ожидания перехода к WRO, затем прошёл с 15s ожиданием (20,6s за запуск). Проверено 64 URL sitemap, без юридических черновиков. Визуально просмотрен калькулятор на 320px; горизонтального переполнения нет. ESLint passed. Это локальные функциональные проверки, не измерение production-производительности.
`npm run build` (production build и TypeScript) прошёл после финальных изменений. Изменения не опубликованы.
