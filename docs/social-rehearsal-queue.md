# Пробная редакционная очередь

29 октября 2026. Это завершённая часть подготовки SOC-03; реальная доставка остаётся
отдельным этапом. Очередь не содержит аккаунтов, токенов и адаптеров соцсетей.
Каждый результат имеет `mode=dry-run`, `publishable=false`, `accounts=[]`.
Технический Telegram мониторинга не используется.

В закрытом редакторе после одобрения доступны «Проверить сейчас» и выбор времени
пробной проверки. Время вводится в часовом поясе устройства, передаётся с UTC-смещением;
результат дополнительно показывает время Варшавы. На сервере наивные даты отвергаются.
Назначенное время должно предшествовать истечению одобрения. В выбранную минуту
обработчик проверяет источник и сохраняет пакет; скачать его можно из редактора.
Таймер запускается раз в минуту, поэтому это не обещание выполнения с точностью до секунды.

Одной неизменяемой версии соответствует одна задача. Повтор идентичного запроса
сохраняет её ID. Изменение времени требует новой версии и одобрения. Правка или
отклонение отменяет задачи предыдущей версии, включая уже подготовленные пакеты.
Отмена не восстанавливается автоматически. Одобрение связано с checksum снимка,
текстов, карточки и каналами; время фиксируется в задаче и аудите.

Состояния: SCHEDULED → READY, EXPIRED или NEEDS_REVIEW; отмена → CANCELLED.
READY означает подготовку JSON/SVG, а не пост в соцсети. Повторное скачивание
снова проверяет цену, даты, событие, условия, шаблон и одобрение. Устаревший пакет
не выдаётся. Уже скачанный файл не получает полномочий на будущую отправку.
Один сбой транзакции оставляет задачу для следующей проверки без внешних эффектов.
Новая версия отменяет старую задачу в той же транзакции.

Все маршруты наследуют вход владельца, Origin и CSRF редактора:

- `POST /api/v1/editor/items/{id}/rehearsal` — `version`, необязательный `scheduled_at`;
  отсутствие времени означает немедленную пробную проверку.
- `POST .../rehearsal/run` — проверить срок/источник, получить пакет, если он готов.
- `POST .../rehearsal/cancel` — отменить текущую задачу.

Обработчик `python -m app.jobs.editor_rehearsal --limit 50` работает только при
включённом редакторе. Он блокирует строки материалов через PostgreSQL
`FOR UPDATE SKIP LOCKED`, в том же порядке, что правка/отмена. Конкурирующие
обработчики не готовят задачу дважды. Сетевых вызовов и флага публикации у команды нет.

## Установка таймера

После миграции `0018_editorial_rehearsal` и запуска обновлённого API:

```sh
sudo install -m 0644 /opt/hoptrip/current/scripts/systemd/hoptrip-editor-rehearsal.service /etc/systemd/system/
sudo install -m 0644 /opt/hoptrip/current/scripts/systemd/hoptrip-editor-rehearsal.timer /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now hoptrip-editor-rehearsal.timer
sudo systemctl start hoptrip-editor-rehearsal.service
sudo systemctl status hoptrip-editor-rehearsal.timer --no-pager
sudo journalctl -u hoptrip-editor-rehearsal.service -n 10 --no-pager
```

Таймер вызывает команду внутри `hoptrip-api-1`, не читает секреты хоста и продолжает
использовать текущий контейнер после deploy. Если редактор выключен, выключить таймер:
`sudo systemctl disable --now hoptrip-editor-rehearsal.timer`.
Перед откатом к версии до этой миграции также выключить таймер; таблицу и историю
сохранять, автоматического downgrade нет. Обычная миграция добавляет только новую таблицу.

## Что ещё нужно для настоящей доставки

Отдельный маркетинговый бот и тестовый канал, привязка аккаунта к новому одобрению,
адаптер (включая растровую карточку), идемпотентность/неопределённый результат отправки,
ограниченные повторы и проверка одного согласованного закрытого поста. Пробные задачи
не преобразовывать в задания отправки. Включение таймера не включает публикации.

Проверки: авторизация и CSRF; даты без зоны/за сроком; дедупликация UTC-смещений;
ранний запуск; повторное скачивание после изменения цены; отмена/правка/отклонение;
истечение/изменение одобрения и шаблона; два конкурирующих обработчика PostgreSQL
и пропуск заблокированного материала. UI-сценарий проверяет desktop/mobile,
выгрузку dry-run, сброс задачи после правки, axe и отсутствие горизонтального скролла.
