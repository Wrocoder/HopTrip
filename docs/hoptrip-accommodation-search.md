# HT-14 — поиск жилья

Изменения 2026-10-12, локально, без публикации.

Форма Stay22 показывает итог: польское название города, даты, ночи и взрослых.
Переход сохраняет address/checkin/checkout/adults, aid=hoptrip,
campaign=hoptrip_accommodation, PLN/pl и партнёрское обозначение.
Пустые/неверные даты, выезд не позже заезда и некорректное число взрослых
исключают ссылку; ошибки связаны с полями через aria-invalid/aria-describedby.
Переход измеряется PARTNER_CLICK/stay/stay22 с действующим согласием.

При доступном flight_facts показаны сохранённые прибытие и обратный вылет
через общий formatter flightTime, явно в UTC. API не передаёт часовой пояс
аэропорта/отеля, поэтому UTC не выдаётся за местное время и дата заезда
не пересчитывается автоматически. Начальные даты — из оферты; пользователь
редактирует их с учётом местной даты прибытия, трансфера и позднего заселения.
Без расписания есть подсказка проверить дату прибытия; one-way требует
даты выезда. Форма жилья не изменяет перелёт и сохранённый план бюджета.

Ссылка добавления стоимости переводит фокус к выбору основания цены в
существующем калькуляторе. Пользователь вводит сумму в PLN за ночь либо
весь период для всей группы/всех комнат с налогами. Даты и состав группы
в бюджете проверяются отдельно; сумма и основание сохраняются черновиком.
Нет автоматического возврата цены от партнёра или вымышленных карточек жилья.

## Ручной сценарий

Открыть предложение → блок Znajdź nocleg → изменить даты и взрослых →
сверить итог → открыть Stay22 → проверить город/даты/гостей у продавца →
вернуться → Dodaj koszt noclegu → выбрать весь период → ввести общую
сумму → проверить даты/людей бюджета → обновить страницу и проверить черновик.

Реальный переход предшествующей версии подтверждён владельцем в HT-05:
Barcelona, 15–17 января 2027, 2 взрослых, Booking.com, PLN. Новый код проверяется
с локальной подменой внешнего перехода: это не новая проверка продавца.
У владельца конечный язык был русский; lang=pl не гарантирует польский интерфейс.
Комиссии и campaign-разбивка кабинета остаются неподтверждёнными.

Изменён компонент trip-accommodation.tsx и расширен accommodation.spec.ts;
расчёты бюджета, API и схема хранения не менялись.
