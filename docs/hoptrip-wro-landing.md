# HT-18 — посадочная вылетов из Вроцлава

Статус: DONE, 2026-10-12.

Канонический адрес сохранён: `/from/WRO`. Страница остаётся index, follow
и входит в существующий sitemap. Дубликаты и новые городские страницы не создавались.

Раньше блок планирования и ссылки шли после всего списка карточек; вводный
текст говорил о форме, которой на странице нет. Теперь перед актуальными
предложениями расположен блок короткого выезда: сначала ссылки на поиск,
аэропорт, бюджет и путеводители, затем короткие пояснения о времени на месте,
доезде, обратном рейсе и расходах. Заголовок сохраняет «Loty z Wrocławia (WRO)»;
title/description конкретизируют выходные и поездки на 2–4 ночи.

| Ссылка | Результат |
| --- | --- |
| Z WRO na 2–4 noce | /deals?origin=WRO&duration_min=2&duration_max=4 |
| Weekend z WRO | /deals?origin=WRO&weekend=true |
| Ustaw daty i budżet dla WRO | /deals?origin=WRO |
| Poradnik lotniska Wrocław | /info/wro-airport |
| Kalkulator kosztów podróży | /info/trip-budget |
| Przewodniki: dojazd i plan pobytu | /info |

Переход к поиску сохраняет WRO и позволяет изменить даты, бюджет и остальные
фильтры обычной формой. Цена — перелёт на человека, не вся поездка. Weekend
обозначает пятницу/субботу до ближайшего воскресенья, без обещания поездки
без отпуска. Пояснение явно отделяет выбранные поисковые условия от списка
ниже: сама посадочная показывает предложения WRO без фильтра по длительности.
Новые цены, расписания и маршруты не добавлялись; карточки используют прежний API.

Проверка tests/wro-landing.spec.ts: desktop 1440 px и mobile 360 px, порядок
навигации до первой карточки, рабочие справочные ссылки, оба поисковых перехода,
сохранение WRO при изменении бюджета, canonical, robots, title, отсутствие
горизонтальной прокрутки и axe на main. Фикстуры проверяют поведение, а не
актуальность реальных авиабилетов. catalog-seo.spec.ts проверяет регрессию
метаданных и PNG-превью, включая аэропорт WRO.

Деплой и продвижение не выполнялись. Страница подготовлена локально; рост
трафика и индексации не заявляется.

Результаты: 2 новых E2E desktop/mobile и 4 SEO/preview E2E прошли; axe без
нарушений на проверенном main, горизонтального переполнения нет. ESLint,
production build с TypeScript и git diff --check прошли. Первые запуски выявили
ошибки самого теста: ожидание заголовка без WRO и чтение URL до завершения
клиентского перехода; исправлены точный заголовок и ожидание навигации.
