# SEO и редакционный план

Обновлено 2026-09-24. Реализованы **35 статей**, включая **18 городских направлений**:
первоначальные 25 материалов и 10 новых гайдов. Sitemap содержит 37 URL
(статьи + главная + `/info`), для статей генерируются 35 PNG-превью.
Сайт работает на https://hoptrip.pl; пока действует общий запрет индексации на Caddy.

## Реальные предложения: авиабилеты и пакетные туры

2026-09-24 владелец подтвердил оба направления продукта. Аккаунта Travelpayouts
пока нет. Текущая реализация flight-only не включает источник пакетных туров.
Приоритет следующего этапа — реальные данные и проверенные ссылки бронирования.

- Авиабилеты: зарегистрировать проект https://hoptrip.pl в Travelpayouts,
  подтвердить доступ к программе и данным для польской аудитории, сохранить токен
  только на сервере. Проверить настоящий ответ API, PLN/market, маршрут, даты,
  цену на человека и переход с атрибуцией. Текущий адаптер читает кеш цен,
  а генерация партнёрских ссылок через API ещё не подключена.
- Готовые туры: кандидат — TravelLead, партнёрская программа Wakacje.pl.
  Официальная страница предлагает генератор deep links, product feed и виджет поиска.
  Заявка проходит проверку; доступ к feed, формат, частота обновления, права на
  фото/описания и условия отслеживания требуют подтверждения для нашего аккаунта.
  Наличие программы не означает уже полученный доступ HopTrip.
- Первые ссылки на туры можно подключить из одобренного кабинета; каталог с ценами
  запускается после проверки feed. Не подменять конкретное предложение общей
  поисковой ссылкой и не публиковать вымышленные цены.
- В интерфейсе нужны отдельные разделы Loty и Wakacje. Для пакета хранить состав,
  организатора, отель, питание, даты/ночи, вылет, число и возраст путешественников,
  валюту, базу цены (на человека/за весь заказ), время проверки и исходную ссылку.
  Не складывать отдельно найденные билет и отель и не называть результат туром
  организатора. Сравнение цен и история пакетов должны учитывать одинаковый состав.

Порядок: регистрация обоих аккаунтов → одобрение/документация и образец ссылки/feed →
интеграция и тест перехода → реальные предложения на сайте. Для описания проекта
указывать польскую аудиторию, существующие 35 гайдов и планируемые разделы;
не заявлять существующие продажи, трафик или уже работающий каталог туров.

Проверенные официальные источники:
[Travelpayouts: регистрация и Project](https://support.travelpayouts.com/hc/en-us/articles/11394852618642-How-to-use-Travelpayouts-Quick-Start-Guide),
[Aviasales Data API](https://support.travelpayouts.com/hc/en-us/articles/203956163-Aviasales-Data-API),
[TravelLead: регистрация, инструменты и проверка заявки](https://www.travellead.pl/).

## Актуализация и приёмка

При изменении источника обновить подтверждаемый раздел и `reviewedAt`. Перед выпуском
повторно проверить багаж, транспортные маршруты, ограничения билетов и terminal/shuttle.
Если факт больше не подтверждается, убрать/исправить его; если вся статья не готова,
установить `draft:true`, чтобы она исчезла из списка и sitemap и получила noindex.

Запуск из `apps/web` в PowerShell с установленным Edge:

```powershell
$env:PLAYWRIGHT_CHANNEL='msedge'
npm run audit:seo -- http://127.0.0.1:58080 http://localhost:58080
```

Первый аргумент — адрес доступного сервера, второй — ожидаемый canonical origin,
заданный при сборке. На production передать фактический HTTPS origin в обоих
аргументах. Без `PLAYWRIGHT_CHANNEL` требуется установленный Playwright Chromium.
Команда использует существующий сервер; не запускает миграции, сборку или фикстуры.
URL из sitemap запрашиваются только через адрес сервера из первого аргумента.
При ошибках exit code ненулевой, результат содержит список нарушений.

Результат 2026-09-23: 27 URL, ошибок нет. Контрольный запуск с неверным ожидаемым
origin обнаружил несоответствия и завершился с кодом 1; frontend lint прошёл.
Неизвестная статья показывает not-found и noindex. Потоковый ответ Next.js может
иметь HTTP 200 (наблюдается в rehearsal); аудит не приравнивает это к отсутствию
страницы ошибки, а проверяет её содержимое и запрет индексации.
