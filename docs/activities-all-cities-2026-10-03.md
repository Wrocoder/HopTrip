# Музеи и развлечения: все города

Дата проверки: 2026-10-03.

Подборки для 68 активных направлений HopTrip: 71 карточка, по 1–2 на город.
32 города / 35 карточек используют партнёрские билеты Tiqets; 36 городов —
официальные сайты музеев, объектов или муниципальной/национальной туристической службы.
Такие ссылки не монетизированы и могут вести к правилам посещения с покупкой билета в кассе.

Новые 65 подборок: `apps/web/src/lib/activity-expansion.json`. Исходные шесть
карточек Милана, Парижа, Барселоны сохранены в `destination-activities.ts`.
В каждой записи указан исходный URL и дата редакционной проверки. Цены и наличие
мест на даты поездки не синхронизируются; пользователь проверяет их у поставщика.

29 новых партнёрских ссылок получены через API Travelpayouts, а не составлены вручную.
Ответы сохранены в `activity-partner-links-2026-10-03.json` (только публичные ссылки).
Использованы подключённый проект 577569, marker 779959, campaign 89 и sub_id
`hoptrip_attractions`; API вернул success для всех 29 продуктов.
Документация: https://support.travelpayouts.com/hc/en-us/articles/25289759198226-API-for-Travelpayouts-partner-links
Токен не передаётся браузеру и не сохраняется в этих файлах.
Это подтверждает создание ссылок, но не регистрацию продаж или выплату комиссии.

Интерфейс различает «Sprawdź daty i cenę» (Tiqets) и «Sprawdź zasady wizyty»
(официальная информация). Пометка о комиссии и rel=sponsored только у партнёрских ссылок.
Все ссылки открываются в новой вкладке с noopener noreferrer. При загрузке блока
запросов к партнёрам нет. Блок не меняет стоимость перелёта.

Проверки перед публикацией: TypeScript, ESLint, 4 Playwright-теста в установленном
Chrome (desktop/mobile), включая axe и ширину 320 px. Сверка API направлений: 68,
пропусков 0. Первый запуск браузерных тестов требовал отсутствующий bundled Chromium;
повторный запуск с PLAYWRIGHT_CHANNEL=chrome прошёл.

Откат web: `hoptrip-web:before-activities-all-cities-20261003`.
Исходники до обновления: `/opt/hoptrip/backups/web-source-before-activities-all-cities-20261003.tar`.
Новый файл `activity-expansion.json` отсутствовал в предыдущей версии.
