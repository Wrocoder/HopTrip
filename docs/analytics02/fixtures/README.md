# Синтетические данные проверки

Все HTML/JSON в этой папке — ответы локального TestClient на изолированной SQLite с явно синтетическими событиями из `test_usage_dashboard.py`. Это не показатели HopTrip production и не baseline. В HTML нет идентификаторов сессий, email, токенов или admin credentials.

Браузерные снимки `fixture-*.png` в родительской папке показывают именно эти данные. Сам dashboard в приложении рассчитывает значения из текущих сохранённых AnalyticsEvent, а не использует эти файлы.
